# Лабораторная работа №8 — Текстурный анализ (контраст по GLCM)

**Вариант 14**

## Цель
Реализовать вычисление признака **контраст** текстуры на основе **матрицы совместной встречаемости уровней серого** (GLCM, Haralick) и получить численные значения для нескольких направлений.

## Краткая теория
1) Строим GLCM `P(i,j)` для заданных расстояния `d` и направления `θ` (пары соседних пикселей).  
2) Нормируем `P` так, чтобы сумма элементов была 1.  
3) **Контраст**:
`Contrast = Σ_i Σ_j (i - j)^2 * P(i, j)`

## Что сделано (вариант 14)
- Градации: `levels = 16` (квантование 0..255 → 0..15)
- Расстояние: `d = 1`
- Направления: `0°, 45°, 90°, 135°`
- Итоговый признак: среднее `contrast_mean` по направлениям

Параметры хранятся в `config/variant14.json`.

## Запуск
1) Установка зависимостей:
`pip install -r requirements.txt`

2) Демо (генерируются тестовые текстуры и считается контраст):
`python src/main.py --demo`

3) Для своего изображения:
`python src/main.py --image path/to/image.png`

Результат выводится в JSON (по каждому направлению и среднее).
